# 安全边界与账号保护

## 2026-10-16 单条消息安全边界

默认关闭的部署开关只允许 message.send；CDP 只读验证 pair，独立导入的 Cookie/WS 负责发送。审批冻结 UID、凭据 digest、CDP endpoint、接管 revision 与完整正文，执行时复核；指纹/端点仅管理员可见。单条 HTTP/UI 执行经过原 action 队列，Agent 无执行权，CDP live 消息不自动消费历史 approved。接管/解除期间 revision 变化使旧授权失效；busy/rate_limit 只可在 revision 不变且未接管时恢复 approved。未知写不重放；只读核对最多等待10秒限速窗口，不跳过暂停/接管。Cookie/IM token 临时文件结束与重启清理；FAQ/首次联系保持关闭。完整来源与 ACK 证据缺口见 [MESSAGE_SEND](MESSAGE_SEND.md)。

## 受控能力

工作台不提供支付、下单、确认收货、退款等执行代码。真实消息和发布默认关闭，须人工审批并由管理员指定单条执行；旧 live delete 禁用；Agent 不能改账号、导入凭据、配置模型或审批。可调用的上游操作是代码白名单，不接受任意模块、命令、脚本或 URL 作为执行目标。

审批绑定账号 ID、模式、操作类型和完整参数摘要。操作内容不可原地修改；改内容需要新申请。图片为上传后只读的内部 ID，执行前校验归属、路径边界和 SHA-256。删除需要明确说明可能不可恢复，并通过上游详情证实归属。

## 保密范围

使用 Fernet 对称加密保存：账号登录态、模型 API Key、操作请求正文、执行结果、本地草稿、人工核对证据摘要。聊天历史按需读取，不自动持久化；发送内容会进入加密的操作正文。

未做应用层加密的内容：商品图片、公开商品台账、搜索监控结果、账号标签与平台用户 ID、审计元数据、任务时间与状态。需要更强静态保护时启用全盘加密并控制备份访问。

XY_VAULT_KEY 与访问令牌位于本地 `.env` 或进程环境。POSIX 创建文件时采用私有权限；Windows 还应使用用户目录 ACL/磁盘加密，不把 chmod 当作完整 Windows ACL 隔离。

接口没有 Cookie/API Key 导出。输入校验错误不回显原始敏感请求体。上游 stdout/stderr 不直接返回，日志只记录错误类型、状态和摘要。HTTP access log 默认关闭。模型只收到用户在“AI 内容助理”输入的资料，不自动获取整个数据库。

## 上游隔离

固定依赖通过独立 Python 子进程调用；不会在 FastAPI/MCP 主进程导入上游业务模块。契约测试确认上游导入存在全局 subprocess.Popen 修改副作用，因此测试本身也用子进程隔离。

每账号独立 HOME、临时 Cookie、设备状态和浏览器目录。禁用自动从本机浏览器引入登录态，禁用登录失效后的自动刷新重试。不自动切账号、代理或网关。程序自身不提供验证码识别/绕过。

正常结束与启动恢复时清理临时 Cookie 和浏览器 profile。运行中的浏览器必须取得可读凭据；强杀、断电和系统崩溃可能留下临时文件，不能声称凭据从未以明文存在。高要求部署应使用加密磁盘或受控临时文件系统，且不要共享操作系统用户。

## 队列与不确定状态

SQLite 事务原子领取任务，单实例文件锁阻止多个队列/恢复进程争抢同一目录。进程间调用串行，真实读取最少间隔 5 秒，真实写入最少间隔 30 秒。搜索监控最短 300 秒。

出现风控/登录失效暂停账号，由主人解决后恢复。超时、崩溃、异常返回不自动重试写入；MCP/HTTP 客户端需复用幂等键。恢复账号不等于恢复旧写任务。

上游 mid 不等于送达；真实发送结果标记 unconfirmed。发布/删除返回接受状态只表示上游响应，仍需核实平台状态。当前账号“暂停”不能撤回已经发出的网络请求。

人工核对仅管理员可写，绑定原账号/原操作，`unconfirmed/submitted/blocked` 允许；`pending/approved/running/failed/rejected/expired/simulated` 拒绝。核对独立表保存，不改变原执行 `state/result/error`；每操作仅一条不可覆盖记录，同键同内容返回原记录，冲突 409，并发仅一次写入。核对与审计同事务；审计只含账号/操作 ID、结论、时间与人工来源，不含证据正文或正文摘要哈希。Agent 仅可读结论与时间等非敏感概要，无核对/审批能力，MCP 不新增写工具。

`observed/not_observed/unresolved` 不是送达/已读状态，也不证明未发生；不得据此重新入队、换键重发或解锁账号。证据使用 textContent 展示，不执行其中 HTML/脚本。消息没有可靠 ACK；发布有精确 ret/同 ID UID/冻结类型状态核对代码但未真实平台验收，不证明内容价格等价，见 [发布执行器](PUBLISH_EXECUTOR.md)。

## 迁移与备份保护

数据库升级持有单实例锁，升级前以 SQLite backup API 保存含已提交 WAL 的一致性快照，事务失败回滚结构/数据/版本。未知未来版本拒绝启动；已有密文在迁移前用配置密钥校验，错误密钥或损坏密文不清空原数据。快照仍含敏感元数据，应限制文件权限并加密磁盘；密钥与完整数据/素材分别备份。没有加密记录的空库无法判定历史密钥。

已有管理员离线 backup/restore CLI；恢复暂停账号/监控/观察、撤销 FAQ、关闭外部通知、使 pending/approved 失效和 running 不确定，保留阶段而不重放。无定时/保留策略，详见 [BACKUP](BACKUP.md)。

## 外部通知授权（2026-10-15）

仅管理员可配置固定 HTTPS 目的地与签名密钥，默认关闭，加密保存、不回显。授权仅覆盖新通知固定摘要，不能发送任意消息、代审批或执行平台写。Agent 只读脱敏投递状态及修改站内已读/归档。公网 DNS 全答案校验后固定连接 IP、TLS 原域名验证、无代理/重定向、有界超时响应；失败最多三次只重试通知，重启在途为 unknown。恢复禁用配置并取消旧待发项。完整威胁边界与重复投递局限见 [NOTIFICATIONS](NOTIFICATIONS.md)。无人值守客服授权未实现，逐条平台审批不变。

## 不涵盖的保证

没有真实账号验收，不保证闲鱼风控、页面结构或非官方接口持续有效。不保证商品真伪、最低价或卖家信誉。人可以审批一条不明智消息，模型也可能生成错误文字，必须核对商品事实和金额。

一个实例面向一个账号主人，不是公开多租户 SaaS；Agent 令牌可以查看实例内所有已配置账号，不包含逐账号 ACL。角色令牌当前为静态环境配置，更换需更新配置并重启，不提供用户注册或密码找回。

同一 OS 用户的任意代码执行、root、Docker socket 或读取 `.env` 的权限可绕过应用审批。远程 Agent 应使用独立用户/容器且仅有 API 权限。裸 HTTP 公网部署不在安全范围内。
