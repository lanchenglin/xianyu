Hermes / MCP 接入
安装本项目的 mcp 依赖后，以 xianyu-mcp 启动 stdio 服务。配置 XY_API_URL 为固定的工作台地址，并只提供 XY_AGENT_TOKEN。
远程网关需要在对应机器上运行 MCP。工作台不会自动换网关、换账号或换登录态。
管理员账号能批准写操作。不要把管理员令牌、.env、加密密钥或服务器文件系统访问权限交给 AI。
